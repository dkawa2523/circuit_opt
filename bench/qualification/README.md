# Equipment qualification

No equipment-qualification case is defined yet because this repository does
not target a specific chamber, matcher, probe chain, or component set.

The engine, model-conformance, source-fidelity, and design benchmarks elsewhere
under `bench/` qualify the reusable calculation workflow. They do not qualify
an apparatus. A future equipment case belongs here only when it has a named
reference plane, authorized hardware and tuner limits, calibrated complex-load
data, and held-out acceptance data from that same equipment family.

An empty directory is therefore the intended current state, not a missing core
benchmark.
