## 次に進めるB

1. **測定面と校正を固定する。** 治具・ケーブル・feedthroughの範囲、V/Iの位相基準、peak/RMS、電流方向、de-embedding手順を記録する。
2. **取得groupを持つ観測を用意する。** 周波数・運転条件・設備control・取得日やcampaignを記録し、同じ取得groupの行をfitとholdoutへ無作為に分散させない。
3. **最小の識別可能な端子モデルを当てる。** 校正値を固定して有界latentだけを推定し、残差の周波数依存、範囲端への張付き、局所rank・条件数を確認する。
4. **未使用条件で予測と判断を確かめる。** 複素Zと電力・制約の誤差を別々に評価する。反復測定は再現性の証拠として区別する。
5. **不確かさと適用範囲を決める。** 校正誤差・ノイズ・条件外挿の影響を調べ、モデルを再利用してよい範囲と再校正条件を定める。

実測データがない段階で、合成データの回収精度を装置精度として提示しない。Bの受入後に、通常の回路計算・最小二乗と比べて学習を加える理由があるかを判断する。

## 残件と改良中に確認した限界

| 項目 | 現在の扱い | 次の対応 |
|---|---|---|
| 実測・校正・ノイズ | 合成回路での回収と局所感度まで検証 | Bで取得groupと校正を含めて評価 |
| 識別可能性 | 局所rankと条件数を返す | 大域的一意性・信頼区間は独立した証拠で評価 |
| SPICE回路図 | 対応する接続を保持し、未解決素子はpartialを返す | 利用するdeviceごとに解析・描画の対応を確認 |
| 再描画 | 単体runの`analyze`を提供 | study/identification全体の再描画は必要性を確認して追加 |
| 再開 | raw結果の再利用と世代保存を提供 | optimizer内部状態の完全再開は未実装 |
| 他環境 | Windowsの2依存環境でwheelを検証 | Linux/macOS・リモートCIは別の実行証拠が必要 |
| 出版済みsnapshot | 生成時の版・source hash・入力を保存 | 最新の機能受入とは区別し、必要時に対象suiteを再現 |

今回の文書確認では、旧負荷文書が同定を将来機能と記しながら実装済みAPIを別文書が説明する矛盾、複数の入出力説明、古い見出しへのリンクが残っていた。現行仕様をマニュアルへ統合し、用途別の研究ノートと固定検証報告は所在と対象範囲を明示した。
